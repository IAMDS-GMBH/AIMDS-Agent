1. Getting started

What it does

Hermes connects your desktop app to your configured AI backend and available tools.

How to use it

  • Run the installer and open Hermes Desktop.
  • Connect with Keycloak (recommended) or provide Base URL + API key.
  • Fetch/select a model and finish setup.

Expected result

You can start a conversation immediately and switch features from the left navigation.

2. Core chat workflow

What it does

Main workspace to ask tasks, receive answers, and execute tool-backed actions.

How to use it

  • Type your request in the composer and send.
  • Attach files/images when needed.
  • Use slash commands like /model, /skills, /new.
  • Interrupt long runs and steer with a follow-up instruction.

3. Sessions and history

What it does

Keeps your chat sessions, lets you reopen context, and manage ongoing threads.

How to use it

  • Select any previous session from the sidebar.
  • Pin important sessions for quick access.
  • Delete/archive sessions when no longer needed.

4. Profiles

What it does

Separates contexts by project/team/use case, including profile-level settings and behavior.

How to use it

  • Create a profile and give it a clear purpose (for example: Sales, PMO, Legal).
  • Switch profile before starting a new topic.
  • Rename or remove profiles from the Profiles view.

5. Models and providers

What it does

Lets you choose the LLM and provider account used for responses.

How to use it

  • Use the status bar model picker or Settings → Model.
  • Configure provider credentials in Settings → Providers / Keys.
  • Use model visibility options to keep only relevant models enabled.

6. Skills and toolsets

What it does

Enables/disables capability packages (skills) and grouped tool permissions (toolsets).

How to use it

  • Open Skills view and toggle specific skills on/off.
  • Switch to Toolsets tab to enable/disable grouped backend tools.
  • Keep only required capabilities active for cleaner behavior.

7. Messaging (Outlook)

What it does

Connects Hermes to Outlook via Microsoft Graph for email, calendar, and contacts actions.

How to use it

  • Open Messaging → Outlook.
  • Enter Tenant ID and Client ID, save, then authenticate.
  • Run Test Connection to confirm access.
Sending emails is confirmation-based: Hermes previews recipients/subject/body first and only sends after explicit confirmation.

8. Memory system (automatic triggers)

What it does

Hermes stores useful long-term context and reuses it in future conversations without requiring manual save commands.

Automatic trigger matrix

Automatic trigger When it happens What Hermes does
Session-start memory load At the beginning of a session Loads persisted memory/profile context into the prompt context used by Hermes.
Per-turn memory recall Each user turn, based on current message relevance Retrieves relevant stored memory snippets and injects them as contextual recall.
Post-turn auto extraction After a completed turn (when capture mode is auto and prefilter conditions are met) Runs a background extraction pass to identify durable facts and store them.
Periodic background review After configured turn intervals Runs a background self-improvement review that may update memory with durable preferences/context.
Personal-context refresh When user asks profile/preference/history-type questions Forces context revalidation to answer with fresh stored personal context.

What is typically stored automatically

  • Stable user preferences and communication expectations.
  • Durable project conventions and useful context facts.
  • Relevant profile signals that improve future answers.

What is typically excluded

  • Short-lived one-off turn details.
  • Transient execution noise that has no long-term value.

9. Scheduled jobs (Cron)

What it does

Runs recurring Hermes tasks automatically on schedule (daily, weekly, custom cron).

How to use it

  • Create a job with name, prompt, and schedule.
  • Pause/resume/run-now from the Cron view.
  • Review latest runs and status in the same screen.
In this client distribution, cron delivery is fixed to Desktop (no destination selection).

10. Artifacts

What it does

Collects links, files, and images generated or referenced during sessions.

How to use it

  • Open Artifacts to filter by type (image/file/link).
  • Open, copy, or jump back to originating session.

11. Agents monitor

What it does

Shows delegated/background agents and their status (running/completed/failed).

How to use it

  • Open Agents view during complex tasks.
  • Track progress, duration, and final state of delegated workers.

12. Todos

What it does

Displays chronological task items grouped by day or week.

How to use it

  • Open Todos and switch grouping (Day/Week).
  • Mark completed items directly in the list.

13. Command Center

What it does

Central control for session actions, system diagnostics, and usage analytics.

How to use it

  • Manage sessions (open/export/delete/pin).
  • Check system/gateway status and logs.
  • Review usage analytics by time period.

14. Settings and support

What it does

Configures behavior and provides support diagnostics/upload flows.

Key areas

  • Model, Chat, Appearance, Workspace, Safety, Memory & Context, Voice.
  • Providers/API keys, MCP configuration, archived chats.
  • Support log upload from About screen when required.

Common support workflow

  • Open About → verify version and update state.
  • Collect/send support logs if requested by support team.
