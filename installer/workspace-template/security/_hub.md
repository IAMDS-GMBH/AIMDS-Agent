# Security

> Security audits, vulnerability assessments, compliance reviews, and access policy records for systems and repositories.

**Belongs here:**
- Security audit reports (`<date>-<system>-audit.md`)
- Vulnerability findings and remediation trackers
- Access governance, credential rotation plans, and compliance checklists

**Does NOT belong here:**
- Plain code bugs without security relevance → `tasks/` or `projects/`
- Live secrets, passwords, or raw private keys (NEVER store secrets in the vault)
