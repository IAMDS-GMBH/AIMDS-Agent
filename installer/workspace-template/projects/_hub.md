# Projects

> Ongoing work WITH a goal and an end. Status lives in frontmatter (projectStatus). Only the user's own open points — team tasks stay in the team's PM tool.

**Belongs here:**
- <name>.md with projectStatus/due; larger projects get a folder with documents/

**Does NOT belong here:**
- Work without an end date → it is an area or knowledge, not a project
- 0 open points in a project file is a GOOD sign — nothing hangs on the user
