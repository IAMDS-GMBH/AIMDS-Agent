# Tasks

> The user's own to-dos only. Team/project tasks live in the team's PM tool (Jira etc.) — this workspace is a personal todo, not project management.

**Belongs here:**
- thisweek.md — current focus, loaded every session
- tasks.md — backlog with due dates

**Does NOT belong here:**
- Team tasks → the team's PM tool
- Project context → projects/<name>.md
