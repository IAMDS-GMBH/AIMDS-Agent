# Reports

> Generated, regenerable data reports — one canonical file per topic and period, rewritten in place.

**Belongs here:**
- reports/<topic>/<topic>-<period>.md created from _templates/report.md (e.g. reports/worklog/arbeitszeit-2026.md)
- Only periods with data; assumptions, method and verification stated so the report can be regenerated

**Does NOT belong here:**
- Retrospectives and daily/weekly reviews → journal/
- Durable knowledge → knowledge/; decisions → decisions/
- Dated copies (_v2, FINAL, CORRECTED) — overwrite the canonical file and bump updated:
